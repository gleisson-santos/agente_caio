# 🔍 Search Action Module

Este módulo garante a onisciência informativa do Caio v5.0.

## 🚀 Como Usar

### 1. Busca Profunda
Use queries precisas para otimizar os resultados da Brave Search.
*Action:* `web_search(query="preço do Bitcoin hoje", count=3)`

### 2. Extração de Conteúdo
Para analisar sites específicos, utilize o fetch para recuperar o corpo do texto processado (Readability).
*Action:* `web_fetch(url="https://...")`
